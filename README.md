# 🖥️ TaskManager

Sistema desktop de gerenciamento de tarefas e agendamentos desenvolvido em **Python** utilizando a biblioteca **Tkinter**.

O projeto foi desenvolvido como uma atividade prática para explorar conceitos de interfaces gráficas, eventos, funções, manipulação de dados e persistência de informações.

---

## 📌 Sobre o projeto

O **TaskManager** permite que o usuário organize suas tarefas e compromissos em uma interface gráfica simples e intuitiva.

Com o sistema é possível:

- Cadastrar tarefas;
- Definir prioridade;
- Definir data e horário;
- Informar um responsável;
- Alterar o status da tarefa;
- Editar tarefas;
- Concluir tarefas;
- Excluir tarefas;
- Pesquisar tarefas;
- Filtrar tarefas por prioridade;
- Filtrar tarefas por status;
- Cadastrar agendamentos;
- Visualizar compromissos;
- Acompanhar indicadores no Dashboard;
- Salvar os dados em arquivo JSON.

---

## 🛠️ Tecnologias utilizadas

- **Python**
- **Tkinter**
- **ttk**
- **JSON**

O Tkinter é utilizado para construir a interface gráfica da aplicação, enquanto o JSON é utilizado para armazenar os dados.
